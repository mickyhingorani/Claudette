# Code review, 7 November 2026: fixes

An independent review of the whole codebase (working tree on `claude/images-callouts-checkboxes`). Each finding is marked **Fixed** or **Not fixed**, with the test that proves a fix.

Where it stands: findings 1 to 6 are committed in "Show images, callouts and drawn checkboxes; fix review findings". Findings 7 to 15 and the restyle work are committed one per fix on `claude/review-fixes`. None of it is merged into `main` yet.

## Important

| # | Finding | Status |
|---|---|---|
| 1 | Importing a symlinked `.md` copies the link, so edits change the original | **Fixed**: imports copy the file the link points to (`testImportingALinkCopiesTheFileItPointsTo`) |
| 2 | Typing lags in long documents: every keystroke restyles everything | **Fixed**: a keystroke restyles only the edited lines, plus anything the new scan reads differently (such as a code block a new fence opened) and the whole code block when the edit is inside one. In a release build at 43,000 characters, a keystroke takes about 37 ms with full layout forced (from about 100 before the review) and restyling itself about 0.2 ms; moving the caret takes about 1 ms. Checked by 1,800 random edits across themes and views matching a full restyle exactly. **Left as is (decided 7 November)**: the whole document is still re-read on each keystroke (about 13 ms at 43,000 characters, roughly 60 ms at book length); re-reading only the edited part isn't worth its risk for documents this size (`testRandomEditsAlwaysMatchAFullRestyle`, `testAKeystrokeRestylesOnlyNearbyText`) |
| 3 | Code blocks with no language re-guess it on every keystroke | **Fixed**: each unlabeled block is guessed once, then colored with that language; a newly opened file guesses again (`testTypingInUnlabeledCodeGuessesItsLanguageOnce`) |
| 4 | An image whose Markdown wraps leaves big gaps when the caret is on it | **Fixed**: the picture's space goes only below the source's last line (`testWrappedSourceReservesThePictureOnce`) |
| 5 | An image directly above a table disappears | **Fixed**: one `StyleMap.merge` copies every field (`imageDirectlyAboveATableIsKept`, `mergeKeepsEveryKindOfResult`) |
| 6 | Images are kept forever, failures never retry, partial URLs are fetched | **Fixed**: pictures live in a size-limited cache, files reload when they change or appear, failed web pictures retry after 30 seconds, nothing over 40 MB loads, and typing an address fetches only once you pause (`ImageLoaderTests`). Pictures on the Mac still decode on the main thread, but only once per change to the file. |

## Refactoring ideas

1. Restyle only the edited paragraphs, not the whole document. **Done** with bug 2. Re-reading only the edited part: left as is by decision, revisit only for book-length files.
2. Merge the near-duplicate table and image overlay code. **Done**: one list of reserved blocks, one layout rule and one placement routine; offsets for removed blocks are dropped (`testRemovedImageLeavesNoStaleOffset`).
3. One `StyleMap` merge that covers every field. **Done** with bug 5.
4. Split `EditorTextView` into caret rules, editing commands and overlay management.
5. Split `HidingLayoutManager` into hiding and drawing.
6. A real cache policy for `ImageLoader`. **Done** with bug 6.
7. Move save, conflict, reload, trash and rename into one document-session type. **Done**: `App/DocumentSession.swift`, with its own tests that need no editor (`DocumentSessionTests`).
8. One "can edit" check for text, table cells and checkboxes.
