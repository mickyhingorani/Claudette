# Code review, 7 November 2026: fixes

An independent review of the whole codebase (working tree on `claude/images-callouts-checkboxes`). Each finding is marked **Fixed** or **Not fixed**, with the test that proves a fix.

## Important

| # | Finding | Status |
|---|---|---|
| 1 | Importing a symlinked `.md` copies the link, so edits change the original | **Fixed**: imports copy the file the link points to (`testImportingALinkCopiesTheFileItPointsTo`) |
| 2 | Typing lags in long documents: every keystroke restyles everything | **Partly fixed**: only changed styles are applied, so a keystroke re-lays out just the nearby text; hidden syntax is indexed; font conversions are cached. In a release build, a keystroke in a 43,000-character document takes about 66 ms (from roughly 100) and a caret move about 1 ms (from about 50). **Still open**: every keystroke re-reads and restyles the whole document; the real fix is refactor 1 below (`TypingSpeedTests`) |
| 3 | Code blocks with no language re-guess it on every keystroke | **Fixed**: each unlabeled block is guessed once, then colored with that language; a newly opened file guesses again (`testTypingInUnlabeledCodeGuessesItsLanguageOnce`) |
| 4 | An image whose Markdown wraps leaves big gaps when the caret is on it | **Fixed**: the picture's space goes only below the source's last line (`testWrappedSourceReservesThePictureOnce`) |
| 5 | An image directly above a table disappears | **Fixed**: one `StyleMap.merge` copies every field (`imageDirectlyAboveATableIsKept`, `mergeKeepsEveryKindOfResult`) |
| 6 | Images are kept forever, failures never retry, partial URLs are fetched | **Fixed**: pictures live in a size-limited cache, files reload when they change or appear, failed web pictures retry after 30 seconds, nothing over 40 MB loads, and typing an address fetches only once you pause (`ImageLoaderTests`). Pictures on the Mac still decode on the main thread, but only once per change to the file. |

## Refactoring ideas

1. Restyle only the edited paragraphs, not the whole document.
2. Merge the near-duplicate table and image overlay code.
3. One `StyleMap` merge that covers every field. **Done** with bug 5.
4. Split `EditorTextView` into caret rules, editing commands and overlay management.
5. Split `HidingLayoutManager` into hiding and drawing.
6. A real cache policy for `ImageLoader`. **Done** with bug 6.
7. Move save, conflict, reload, trash and rename into one document-session type.
8. One "can edit" check for text, table cells and checkboxes.
